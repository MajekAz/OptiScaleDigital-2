# Images Directory

Upload your custom brand images and assets to this folder.

## Recommended Structure:
- `logo.png` (Company Logo)
- `hero-bg.jpg` (Home page banner)
- `about-team.jpg` (Team photo)
- `service-web.jpg`
- `service-ai.jpg`
- `service-marketing.jpg`

## How to use:
1. Place your image files here.
2. Open `assets.ts` in the root directory.
3. Update the corresponding URL to point to your local file.
   Example: Change `logo: "https://..."` to `logo: "/images/logo.png"`
